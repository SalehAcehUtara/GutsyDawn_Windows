          1. Informasi Repository & Cloud Storage
      
        Seluruh aset suara (1.731 file) disimpan dan di-hosting secara publik di cloud repository Hugging Face Datasets dengan rincian:
      
        • Nama Repository: 
        salehganteng/gutsy_dawn-voicepack
      
        • URL Repository: 
        https://huggingface.co/datasets/salehganteng/gutsy_dawn-voicepack
      
        • Format File: 
        .ogg (Ogg Vorbis) dan .wav
      
        • Folder Utama: 
        stw/
      
        
        
          2. Rumus Direct Link Audio (Direct Streaming URL)
      
        Untuk memutar audio secara langsung (streaming) di Website, Game Engine, maupun Bot tanpa perlu men-download seluruh file ke perangkat lokal, gunakan format URL berikut:
      
        
        
          https://huggingface.co/datasets/salehganteng/gutsy_dawn-voicepack/resolve/main/stw/NAMA_FILE.ogg
      
        Keterangan: Sisipan kata "/resolve/main/" adalah instruksi khusus agar Hugging Face langsung mengalirkan binary audio murni berkecepatan tinggi tanpa antarmuka web.
      
        
        
          3. Contoh Penerapan Kode (Code Implementation)
      
        A. Di Website (HTML5 & JavaScript Native)
      
        
        // Fungsi pemutar SFX otomatis
function playSound(fileName) {
  const baseUrl = "https://huggingface.co/datasets/salehganteng/gutsy_dawn-voicepack/resolve/main/stw/";
  const audio = new Audio(baseUrl + fileName);
  audio.play().catch(e => console.error("Audio error:", e));
}

// Contoh pemanggilan efek suara:
playSound("woodstep1.ogg");   // Suara langkah kaki
playSound("wolfattack.ogg");  // Suara serangan serigala
playSound("wind1.ogg");       // Suara angin malam

          5. Cara Menambah / Mengupdate Audio Baru via Git
      
        1. Clone repository ke komputer pengembang:
      git clone https://huggingface.co/datasets/salehganteng/gutsy_dawn-voicepack
      
        2. Salin file audio (.ogg/.wav) baru ke dalam folder stw/.
      
        3. Commit dan push ke Hugging Face:
      cd gutsy_dawn-voicepack
git add .
git commit -m "feat: tambah audio efek baru"
git push origin main
